# Protective-stop watchdog

On each reconciliation, QAT compares every held QAT position with its signed entry plan and the complete IBKR open-order book. A Phase 1 position has one full-quantity QAT-owned stop at the approved price. A Phase 3 card position has separate banked and runner legs: each stop must match its approved quantity, price, permanent ID and order reference, and the leg quantities must sum to the held quantity. An OCA target must match its own approved identity and terms. TWS and other-client orders remain visible as duplicate risk but never count as QAT-owned protection.

Card-leg terms belong in `approved_protection_legs.json` in the QAT data directory, separate from `open_position_entries.json` because the legacy entry writer rewrites that file after fills. The record for a symbol is `{"entry_order_id": "<signed entry ID>", "legs": [{"role": "banked", "quantity": ..., "stop_price": ..., "order_ref": ..., "perm_id": ..., "oca_group": ..., "target_order_ref": ..., "target_perm_id": ..., "target_price": ...}, {"role": "runner", "quantity": ..., "stop_price": ..., "order_ref": ..., "perm_id": ...}]}`. A stale entry ID, incomplete leg, or total quantity different from the holding blocks restoration. The current shadow card path cannot transmit entries and does not write this file; card transmission must persist its signed plan before it is enabled.

When a leg is absent, QAT alerts and trips the kill switch. It may restore only one confirmed missing leg at a time, at the approved quantity and stop price, after a second broker read and a completed cancellation for that leg's permanent ID. A working, pending-cancel or unidentified order blocks transmission. The replacement's identity is recorded in `protection_leg_lineage.json`; an uncertain acknowledgement keeps the recovery record and cannot submit twice. Confirmation does not reset the kill switch. The operator must reconcile and clear it through the separately approved reset procedure.

IBKR [documents](https://www.interactivebrokers.com.au/en/trading/ordertypes.php?m=hiddenModal) scheduled GTC cancellation at the end of the following calendar quarter, with the last trading day substituted when quarter-end is closed, and a new auto-expire date after modification. QAT calculates the warning date from its placement record, without trusting the API's auto-cancel field. It alerts from 30 calendar days before that date. For a manual stop whose placement date is unknown, it records first sight and alerts immediately. The dashboard keeps the warning visible while the stop remains. Corporate-action warnings require a real DS-pinned authority file and its SHA-256; without one, that check is inactive. Splits or dividends listed before the next ASX session trigger a warning because IBKR may cancel the stop sooner.
